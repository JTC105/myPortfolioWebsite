# Personal Portfolio

This is a personal portfolio built using React, HTML, CSS, and JavaScript. The portfolio showcases various sections including a sidebar navigation, hero section, about me, skills, projects, testimonials, and a contact form.

## Features

- **Sidebar Navigation**: Easy navigation to different sections of the portfolio.
- **Hero Section**: A welcoming introduction with a call-to-action.
- **About Me**: Information about the portfolio owner.
- **Skills**: Display of technical skills using Devicon icons.
- **Projects**: A grid layout showcasing various projects with cards.
- **Testimonials**: A slider displaying testimonials from clients or colleagues.
- **Contact Form**: A form for users to reach out, with validation logic.

## Technologies Used

- React
- HTML
- CSS (Modular CSS)
- JavaScript
- Framer Motion (for animations)

## Getting Started

To get a local copy up and running follow these simple steps.

### Prerequisites

- Node.js installed on your machine.

### Installation

1. Clone the repository
   ```bash
   git clone https://github.com/yourusername/personal-portfolio.git
   ```
2. Navigate to the project directory
   ```bash
   cd personal-portfolio
   ```
3. Install the dependencies
   ```bash
   npm install
   ```
4. Start the development server
   ```bash
   npm run dev
   ```

- Modify the components in the `src/components` directory to customize your portfolio.
- Update the data in the `src/data` directory to reflect your projects, skills, and testimonials.
